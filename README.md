# Prestige Signature Cleaning website

Static website for Prestige Signature Cleaning Ltd, hosted on Netlify.

- Pages are plain HTML files in the root of this repository.
- Edit content through the admin dashboard at `/admin` (password protected).
- Admin saves go straight to this repository and Netlify publishes them automatically.

Netlify environment variables used by the admin: `ADMIN_PASSWORD`, `ADMIN_SECRET`, `GITHUB_TOKEN`, `GITHUB_REPO`.
